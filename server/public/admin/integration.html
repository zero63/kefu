多渠道接入 API

通过统一 REST API 把微信公众号、视频号、抖音、邮件、APP 等渠道接入 kefu 系统。下方列出所有公开端点，可在「开发者 ID」中配置 AppKey/AppSecret 后使用。

1️⃣ 消息接入 API
端点说明
POST /api/visitor/message/send访客发送消息（无需鉴权，已限流）
POST /api/visitor/message/handoff访客主动请求转人工
POST /api/visitor/auth/weapp微信小程序授权登录（拿 openid）
POST /api/visitor/auth/h5H5 端匿名会话创建
2️⃣ 公众号 / 视频号 / 抖音 接入流程
  1. 在「开发者 ID」页配置 AppKey / AppSecret
  2. 将渠道 Webhook URL 配置到对应开放平台
    • 📨 微信 / 视频号：https://kefu.xiaozhusho.top/api/channel/wechat/webhook?appkey={你的AppKey}
    • 📨 抖音：https://kefu.xiaozhusho.top/api/channel/douyin/webhook?appkey={你的AppKey}
    • 📨 邮件（IMAP 拉取）：在「系统集成 → CRM 对接」配置收件 URL
  3. kefu 自动将渠道消息转为标准会话，分配给在线客服
3️⃣ 内部推送 API
端点说明
POST /api/agent/message/send客服主动发消息（需 Bearer Token）
POST /api/agent/session/transfer转接会话给其他客服
POST /api/agent/session/close关闭会话
POST /api/ticket/create创建工单
POST /api/ticket/from-session从会话一键建工单
4️⃣ Webhook 推送（接收事件）

在「链接外接 / Webhook」配置接收 URL，kefu 将以 POST 方式推送事件。请求头包含： 

X-Kefu-Signature: HMAC-SHA256 签名
X-Kefu-Timestamp: 推送时间戳
X-Kefu-Event:     事件名（如 session.new）
Content-Type:     application/json
{
  "event": "session.new",
  "tenant_id": 1,
  "data": { ... 业务字段 ... }
}

💡 签名算法：hash_hmac('sha256', $timestamp . '.' . $body, $secret)

5️⃣ 长轮询（替代 WebSocket）

Windows 环境下 WebSocket 不可用，可使用 HTTP 长轮询：

端点说明
GET /api/poll/agent客服端轮询新消息
GET /api/poll/visitor访客端轮询新消息
GET /api/poll/role/{role}按角色轮询（如 /api/poll/role/admin）
6️⃣ 鉴权说明
  • 管理后台 / 客服工作台：Authorization: Bearer {jwt_token} + Token 续期
  • 访客端：?token=xxx + 服务端 IP 限流（默认 60 条/分钟）
  • 开放 API：使用「开发者 ID」中的 AppKey + HMAC 签名
